Provision data is from the State Firearm Laws Database (Siegel et al., Boston University) — a 2020 baseline with curated 2021–2025 updates layered on so it reflects current law (a production build keeps it current automatically via the LegiScan/Open States pipeline). Category labels are simplified renderings of the official codebook. A state's grade reflects how few of the 134 tracked laws it has (A = fewest, F = most) — the opposite orientation from gun-safety scorecards. The letter grade is always shown, so the map stays readable for color-blind users. Always consult official state statutes and an attorney. Map geometry: us-atlas (US Census, public domain).
